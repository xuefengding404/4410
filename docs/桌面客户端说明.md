# 星语剧场 · 桌面客户端说明

## 方案

Tauri 2 + WebView2，NSIS 按用户安装，不需要管理员权限。

| 项目 | 内容 |
| --- | --- |
| 安装包 | `starry-theater-geek-setup-1.0.0.exe`（约 16.8 MB） |
| 安装目录 | `%LOCALAPPDATA%\StarryTheater Geek` |
| 数据目录 | `%LOCALAPPDATA%\com.starrytheater.geek\EBWebView` |
| 运行要求 | Windows 10/11 + WebView2（系统自带） |

## 构建

```powershell
pnpm build
pnpm tauri:build
```

`scripts/build-tauri.ps1` 使用 Rust GNU + MinGW 工具链（不需要 Visual Studio）：

1. 构建前端到 `dist`；
2. 如果项目路径含中文，创建 `C:\Temp\starry-tauri-src` 的 ASCII junction；
3. 把 `icon.ico` 复制到 `C:\Temp\starry-icons`（windres 读不了中文路径）；
4. 设置 GNU 链接器与 `CARGO_TARGET_DIR`；
5. 构建 NSIS 安装包并复制到 `..\starry-theater-installers\`。

## 数据

- 对话、角色、分支树、手账、皮肤都在 WebView2 的 IndexedDB 里。
- 换电脑用「设置 → 备份与数据」导出 `.json`，到新机器导入。
- 卸载程序不会删除数据；要彻底清空需手动删除数据目录。

## 已知限制

1. 安装包未代码签名，Windows 可能提示「未知发布者」。
2. 没有自动更新，升级需要重新下载安装包覆盖安装。
3. 安装包请从英文路径运行（例如「下载」文件夹）；某些受保护目录会阻止 NSIS 解压。
4. 安装后的程序在中文路径下可正常启动。

## 验收

- 静默安装 `/S` 退出 0，安装目录存在。
- 启动窗口标题「星语剧场」，立绘、雨夜咖啡馆、对话框正常。
- 语音包 `/assets/voice/ella/index.json` 返回 200。
- WebView2 数据目录自动生成。
